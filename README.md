# 🌍 Climate in Colour

### One planet. Two programming languages. Endless ways to tell its story.

A personal data visualisation project exploring climate change through **R, Python, and visual storytelling**.

Inspired by the [**Riffomonas Project's Climate Change Data Visualization series**](https://www.youtube.com/watch?v=d5dUkO5lXds&list=PLmNrK_nkqBpJTSHf3IsN_K_pjFu58z9Oq), this repository documents my journey from recreating visualisations in R to independently translating and experimenting with them in Python.

From global temperature anomalies and warming stripes to climate spirals, animations, and interactive maps, the project explores different ways of making climate data meaningful, engaging, and visually compelling.

Original tutorials and educational materials belong to their respective creators. Data sources and chart inspirations will be credited throughout the repository.
